Stage directions guide

Easiest: tell Claude the story idea and paste the directed script it writes. Direction lines go inside [story] before the spoken line they lead into; they run in order, then the line plays. & at the start means “at the same time as the line above”.

> Mika enters left · > Alex walks to the cotton candy stall · > both run to center · > both exit right
> Mika looks confused (confused, surprised, happy, sad, shy, neutral) · > Alex faces Mika · > Mika waves / jumps / laughs / nods / cheers
> Alex buys cotton candy · > both eat · > Mika gives the ticket to Alex · > both drop (items: cotton candy, ice cream, balloon, ticket, drink, bag, book, popcorn, plush)
> both ride the carousel · > both ride the ferris wheel (amusement park) · > wait 1.5 · @scene zoo changes the place.
Places: amusement park, shrine, zoo, aquarium, cafe, classroom, station, store, home, bookstore, restaurant, airport, street, park, beach, hospital, sakura. Full list with the spots you can walk to: DIRECTING.md in the repo. Without any directions the characters just stand in place like the original Tiny Japanese.

Director prompt (turn a story idea into a script)

Copy this prompt, paste it into any Claude chat, then add your story idea in the same message (for example: “Story idea: Mika and Alex go to the zoo, see a giraffe, and Alex gets scared of the elephant. Lesson: animals.”). Claude replies with a finished script. Paste that script in the box above.

One-time setup: GitHub access token

Create a fine-grained token at GitHub → Settings → Developer settings → Fine-grained tokens. Limit it to the repository tiny-japanese-story with Contents: read/write and Actions: read/write. It is saved only in this browser.
